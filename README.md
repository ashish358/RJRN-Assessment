# Naksh Jewels – ReactJS & Node.js Internship Assessment

## Overview
A mini e-commerce module built to demonstrate frontend, backend, and Docker fundamentals.

## Tech Stack
- React (Vite)
- Node.js + Express
- Context API
- Docker & Docker Compose

## Features
- Product listing
- Add to cart
- Cart management with quantity update
- API-based data flow
- Dockerized setup

## How to Run
1. Clone the repository
2. Run `docker-compose up --build`
3. Frontend: http://localhost:5173
4. Backend: http://localhost:5000/products

## API Endpoints
- GET /products
- POST /cart
